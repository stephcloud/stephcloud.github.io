#  DevOps Portfolio Website

This repository contains my personal portfolio website, showcasing my journey into DevOps, cloud computing, and infrastructure automation.

🔗 **Live Website:** https://afunogu.online

---

##  About This Project

This is a static portfolio website built to present my skills, projects, and growth as an aspiring DevOps Engineer.

The site was initially deployed using **AWS S3 static website hosting**, and later migrated to **GitHub Pages** with a custom domain for easier accessibility and continuous updates.

---

##  Technologies Used

* **HTML5 & CSS3**
* **Git & GitHub**
* **GitHub Pages (Hosting)**
* **AWS S3 (Initial Deployment)**
* **Custom Domain (afunogu.online)**

---

##  Deployment Journey

* Built a static website using HTML and CSS
* Configured AWS S3 for static website hosting
* Managed bucket permissions and public access settings
* Migrated deployment to GitHub Pages
* Connected a custom domain (`afunogu.online`)

---

##  Features

* Responsive personal portfolio website
* Clean UI showcasing profile, resume, and projects
* Social media integration (GitHub, LinkedIn, etc.)
* Easy navigation and structured layout

---

##  What I Learned

* Hosting static websites on AWS S3
* Managing cloud permissions and access control
* Deploying websites using GitHub Pages
* Connecting a custom domain to a hosted site
* Structuring a personal portfolio for visibility
